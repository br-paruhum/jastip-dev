# Project Identity: proxybuying.com

## Overview
proxybuying.com is a platform designed to facilitate secure global and domestic (inter-city) proxy shopping. It solves the logistical and trust issues of buying goods from other regions by connecting buyers with verified local proxy shoppers and carriers.

## Core Features
1. **Escrow/Secure Payments:** Protects buyer funds until the goods are successfully delivered.
2. **Proxy Buyer Network:** A curated, country-specific/city-specific directory of trusted shoppers.
3. **Carrier Matching:** Attracts and matches travelers/carriers to transport purchased goods to the buyer's destination.

## Technical Architecture
* **Backend Framework:** Django (Python)
* **Database:**  PostgreSQL
* **Web Server / WSGI:** Nginx + Gunicorn
* **Current Status:** ~85% complete. Moving toward production readiness.
