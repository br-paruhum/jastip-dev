# Development Workflows & Instructions

## Core Objective
Assist the user in completing the remaining 15% of proxybuying.com, preparing the application for a stable production launch.

## Task Execution Workflow
1. **Analyze:** Locate and read the relevant Django apps, `models.py`, `views.py`, or `urls.py`.
2. **Educate:** Briefly explain the planned implementation strategy to the user.
3. **Draft & Refine:** Modify the codebase cleanly.
4. **Document:** Update the project's internal documentation inside this vault whenever a new feature, database migration, or API route is successfully finalized.

## Code Standards
* Use explicit Django generic views or well-documented function-based views.
* Ensure all models extending user behavior or handling transactions contain robust field validations.
