# User Profile: Lead Developer

## Technical Background
* **Primary Role:** Product Owner and Core Developer.
* **Django Proficiency:** Comfortable with core application logic and workflows.
* **DevOps/Infrastructure Knowledge:** Intermediate. Understands PostgreSQL but relies on AI assistance to configure and debug deployment-level software like Nginx and Gunicorn

## Preferred Communication Style
* Provide clear, concise explanations of backend changes.
* Break down complex tasks into step-by-step modular milestones.
* Act as a coding mentor: explain *how* a specific Django mixin, middleware, or Nginx block functions when implementing new updates.
